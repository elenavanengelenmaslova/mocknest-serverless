# What is Kiro?
I am using Kiro daily for building an gentic system for a startup. However it all started with my AIdeas 10000 competition, for which Kiro was one of the requirements. I was an a rush to start, so I installed Kiro and read getting started docs. I setup steering documents, and followed the steps getting started flow suggested. Installed a couple fo plugins to improve my Kotlin developer experiece and started working on the competition project. I did not stop and resource how I should best create steering docs, so they had a lot of fluff. Market position of my product, coparison with competitors etc. This kind of information might be useful if you are breanstorming new features, what to build but is not needed to actully implement features. 

Additionally I though i shoould pick the best model for everything. I though ok Opus 4.8 (at the time best available) will save me more time building. I did not set up and Skills or Hooks and did not have any filtering when to apply steerign files so they would apply to everything.
